# Невская Верста

Приватный концепт для кандидата C-069 (yandex:59652508059). Статический сайт ресторана и банкетного зала в Санкт-Петербурге. Не официальный сайт. Публичный запуск не согласован.

## Запуск и production

Исходный HTML/CSS и оптимизированные изображения находятся в `dist/` и являются готовой production-версией. Зависимостей, установки пакетов, транспиляции и серверного JavaScript нет. Это намеренный статический проект для небольшого VPS.

```sh
node validate.mjs
python3 -m http.server 4175 --bind 127.0.0.1 --directory dist
```

Воспроизводимая проверка production: `node validate.mjs` проверяет локальные ресурсы, якоря, уникальность ID, метку приватного демо и отсутствие форм сбора данных. Для размещения нужен только `dist/`; исследовательские документы не входят в публичные файлы. Приватность обеспечивает ограничение доступа хостинга; robots/noindex лишь запрещают индексацию и не заменяют авторизацию.

Источник адреса, телефона, категории и двух залов: https://yandex.com/maps/org/nevskaya_versta/59652508059/ . Меню: https://yandex.com/maps/org/nevskaya_versta/59652508059/menu/ . Полные ссылки и ограничения проверки от 11.09.2026 — в BRIEF.md.

Фотографии из карт не копировались. `dist/assets/river-evening.webp` и его малая версия — одна авторская иллюстрация ImageGen. Это художественный образ Петербурга, не реальный вид из ресторана. На сайте есть явная подпись. Промпт сохранён в ARTWORK.md. Наборный знак НВ создан для концепта, не воспроизводит официальный логотип.

Все действия ведут на подтверждённый публичный номер или точную карточку карт/меню. Нет форм, аналитики, трекеров, сторонних шрифтов и автоматической отправки сообщений. Звонки в ходе проверки не совершались.

## Перед запуском

Согласовать с владельцем часы 12:00–23:00, тексты, визуальное направление и право на использование названия; при замене иллюстрации получить разрешение на реальные фото. Не заявлены неизвестные вместимость, цены, свободные даты и условия банкета.

Обязательное сохранение в GitHub блокировано: токен CLI недействителен, подключение не имеет инструмента создания репозитория, доступные существующие репозитории относятся к другим проектам. Исходный код сохраняется в приватном хранилище Sites, но это не заменяет этап GitHub. После восстановления входа создать отдельный приватный репозиторий `nevskaya-versta-demo`, отправить проверенный коммит и обновить рабочую книгу.
